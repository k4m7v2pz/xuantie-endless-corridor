# 设计待落地清单（2D 图块原型）

> 用途：把"想清楚但还没实现"的口径集中在这里。换工具、换窗口、换人都能接上。
> 状态：✅ 已落地 / ⏳ 已定口径未实现 / ❓ 待拍板。
> 只记**决定与理由**，不记实现步骤（步骤看代码与 `docs/图块与两格高物件.md`）。

## 0. 顶层原则：默认即合格

这套引擎不是给会做游戏的人用的，是给**只会写剧情的人**用的——B 站上大量喜羊羊同人恐怖
实况就是反例：脚步一律一条穿鞋声、室内外混响不分、地面材质零信息、闪图还非等比拉伸，
"能玩但很枯燥"。所以引擎的第一职责不是"给足自由度"，而是**默认就做出能听、能看的结果**，
让人只操心内容。三条承诺：

| 承诺 | 默认怎么做 | 人只负责 |
|---|---|---|
| **默认能听** | 材质 → 脚步（含抖动）、几何+吸声 → 混响，全自动 | 说"这间是地毯、堆满沙发" |
| **默认比例正确** | 贴图按 `格边` 整数倍等比绘制、点采样，禁止拉伸填格 | 只提供图 |
| **默认结构完整** | 剧情节点缺 `对/错`、危险前缺场景提示 → **校验器报错**，不许出包 | 写文案 |

推论（重要，别在实现时忘了）：**覆盖是例外，不是流程**。凡是需要人手调参数的，
先问一句"能不能从已有数据推出来"——能推就自动，手调值只作后备出口。

✅ 开屏提示两屏（原型级，`1e89f65` 起）：`原型/提示.json` 槽位 + 三级优先级 + 来源标注 +
逐行渐显 + 任意键跳过，实测两屏后正常进主菜单。
⏳ 开屏提示未做部分：首次一次持久化、闪图标记自动来源、整屏模式、多语言。
⏳ 开屏警告与健康忠告（口径见 `docs/启动警告与健康忠告.md`）：Rust 版有实现可照搬
（`enable_china_mainland` 布尔 + 文案可换 + 三条警告），本仓尚无。**合批成最多两屏**
（内容提示 / 声明与致谢），屏内逐行渐显、不逐条淡入淡出，合计 ≤8 秒可跳过；
内容提示由「内容标记」推出（有闪图就自动出癫痫行），作者只填布尔；忠告走底部淡字。

⏳ 素材侧五件（口径见 `docs/素材与画面约束.md`）：槽位比例检查 → 精灵缺帧回退
→ 精灵帧一致性体检（脚底线/中心/头身轴，给校正参数）→ 闪图时长/频率钳制
→ 来源登记与署名清单。第一条最便宜、收益最大。

## ⏳ 已定口径、未实现

1. **脚步：材质优先**（详见 `docs/音频设计-脚步与材质.md`）
   这一层要回答的是「只靠耳朵能不能听出踩在什么上」，所以材质是第一维，
   脚部（鞋/光脚，拟人不设"爪"）是性格层，速度是节奏层。验收判据是**三步盲听
   能说出材质**；两种材质听混就是这一对要重做。
   不做冷暖、不做扎脚受伤——那是"光脚体验"类游戏的机制，不是恐怖游戏的信息层。
   混响默认**全自动**：几何（宽高/长宽比）给尾巴长短，吸声（`地面` 材质 + 软装关键字）
   给尾巴剩多少；室外归零。写剧情的人只写 `软装: ["沙发"]` 这种词，不调数值；
   `混响` 手调值只作后备出口。
   实现约束：`加载音效 + 播音效` 没有音量/音调控制，抖动与混响必须走 `合成器`，
   且启动时预生成有限变体，不许在走动循环里现合成。
   **待拍板**：真实派（慢走极轻）还是反馈派（慢走留提示声）；我倾向真实派，
   但保留 −18 dB 底线，免得玩家怀疑按键没生效。
   **引擎默认脚部 = 鞋**（安全默认，陌生角色不会突然变成肉垫声），
   **主角显式设光脚**；光脚/木地板既是基准也是角色签名，优先打磨到好听。
   落地时机：等有闲、用户愿意逐条试听时，**不批量生成**。

2. **一次性事件（内容的第一步）**
   现在调查只是吐一段固定文字，读完再看还是一样。需要的最小机制：
   `读过即变`（换描述 / 消失 / 打开）与 `解锁条件`（例如读完一号柜子后另一张图的
   门才亮）。建议顺序 2 → 1 → 3（事件 → 房间数量 → 音效），因为事件最便宜、
   最能改变"这游戏有进展"的判断。**待用户拍板是否按此顺序开工。**

3. **房间数量与回廊结构**
   目前三张（16×10、10×8、18×7），双向连通。要成"回廊"至少四到六张，
   并有单向门 / 回头路。加图成本已降到"写一份房稿 + 跑一次造图.py"。

4. **换图过渡**
   现在换图是瞬切。候选：黑场 0.3s、脚步回声、推门声。**先要哪个未定。**

## ❓ 待拍板 / 未动

- **剧情内容由谁写**：由用户给文本、Agent 接进 JSON，还是 Agent 起草再由用户改。
- **2D 版与 TUI 版的关系**：是否共用一套剧情 JSON（TUI 已有《恐哀》《我还会回来》）。
- **光照/手电筒**：`主函数.xt` 里有最小切片；图块原型还没接光照层。
- **存档**：v1 已实现（六槽、`saves/槽N.json`、存档/读档界面），口径见
  `docs/存档界面设计.md`；自动存档位、缩略图、备注/排序/备份都没做。
- **字体**：目前 Arial Unicode + 参考串烘焙；是否换像素字体（美术阶段再定）。
- **音频会话的开场**：第一次出声前必须先报"播什么、几段、多长"。

## 已知的取舍（别再翻案，除非有新证据）

- 格边定 48，两格高物件 48×96，Retina `@2x` 96×192。改这个只影响出图，不影响逻辑。
- 美术先色块。**AI 更擅长产程序，不擅长产美术**——先丑后美是刻意选择。
- 渲染库 1.3.11 没有源矩形贴图（`绘纹理区` 无 src 参数），纹理池上限 32；
  图块集方案待上游加 `绘纹理源区`，当前用色块与程序化图形。
- 引擎不带剧情文案：跨场景的气味/温度提示**先问人**，不内置。
