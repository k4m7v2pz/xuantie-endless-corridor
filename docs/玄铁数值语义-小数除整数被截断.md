# 玄铁数值语义：`小数(x) / 整数` 仍被截断为整数

> 状态：实测，未上报。与"浮点长循环内存线性上涨"是两件事，单独记，别混进去。

## 现象

```text
示(3 / 48000)          → 0
示(3.0 / 48000)        → 6.25e-05
示(小数(3) / 48000)    → 0        ← 这里
```

最后一行是关键：`小数()` 看起来把值转成了浮点，但**与整数混算的除法仍按整数截断**。
于是"我已经用了 小数()"是一种错觉。

## 为什么危险

它让"看起来是浮点"的表达式静默变成整数，且不报错。与
`docs/玄铁缺陷-浮点逐样本运算内存暴涨.md` 叠加时最坑：写复现的人以为自己在跑浮点，
实际上循环里全是常量，于是缺陷测不出来，还会误判成"没这个问题"（初版文档就栽在这里）。

## 规避

- 混算里至少一侧先写成浮点字面量：`个 * 1.0 / 率`；
- 别依赖 `小数()` 改变后续运算类型；
- 数值相关的复现脚本，先 `示()` 一次中间值确认它真的是小数。
