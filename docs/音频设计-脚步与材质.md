# 音频设计：脚步（材质优先）

> 状态：**设计定稿，未实现**。一条 WAV 都还没做，这里先把口径钉死，
> 等有闲时按「逐条试听」的方式落地（流程见第 8 节）。

## 0. 这一层要回答的问题

不是"人走路该有什么声"，而是：**玩家光靠耳朵，能不能听出自己踩在什么上**。

这是恐怖游戏里最划算的一类信息：不用弹字幕、不用打光，走三步就知道自己在木地板、
瓷砖、金属格栅还是积水的洞里。做到这一步，环境就"活"了；做不到，堆再多美术也空。

## 1. 优先级：先材质，后脚部，最后速度

三者的地位**不平等**，别平铺：

1. **材质（主）** —— 玩家要的信息。每张地图一个 `地面`，必须做得彼此可分。
2. **脚部（性格）** —— 鞋 / 光脚。玩家几乎不会主动注意，但它决定"这个人是谁"。
3. **速度（节奏）** —— 慢走极轻、跑动明显且时大时小。它管真实感与紧张度。

所以数据表以**材质**为第一维：新增一个房间只需加一个材质，所有脚部自动继承；
脚部是角色属性，稀疏、可以缺省回退。

## 1.1 信息半径：光很小，声很大

恐怖游戏普遍把环境光压到只剩玩家周围一圈油灯。这时**声音是唯一能越过光圈的感官**，
脚步的价值不只是"好听"，而是**扩大玩家的感知半径**：

- 光告诉我脚下这三格是什么，声音告诉我这一整段走廊是什么材质、多大、空不空。
- 因此脚步的**材质辨识度要优先于"像不像真实走路"**：玩家在暗处靠它认路，
  做得再真、听不清是木头还是铁，信息就是零。
- 房间混响因此也是信息（"这间屋子很大，回声拖了半秒"），而不只是氛围滤镜。

配套的一条设计约束：**抖动不能吃到辨识度**。音调与音量可以抖 ±3%、±3dB，
但**材质的 EQ 特征（高频含量、尾巴长短）必须锁死**，那条是"信息位"。
抖多了就变成"每步听起来都不一样"，玩家再也学不会这个材质长什么样。

## 1.2 审美目标：不只是信息，也要好听

主角定成光脚之后，脚步声就成了**角色的签名**：一场戏要听上千次，只做到"能分辨"
是浪费。这一层的目标有两个，且允许冲突时由人拍板：

| 目标 | 说明 |
|---|---|
| **信息** | 三步内听出材质（第 2 节的验收判据） |
| **审美** | 光脚踩木地板那个"拍"要好听，值得反复听，甚至让人愿意多走几步 |

冲突时怎么取舍：**信息优先，审美其次**，但只要信息过关，剩下所有余量都花在好听上。
（这也是"光脚慢走到底极轻还是保留一点"那个取舍的另一半理由：完全不响，
既没信息也没审美。）

### 不做的事（划清边界，防以后被加进来）

- **不做冷暖**：踩上去是凉的还是热的，属于"光脚体验"那一类游戏，不是恐怖游戏的信息层。
- **不做扎脚 / 疼痛 / 受伤**：地面碎片刺脚、玻璃碴子掉血，那是玩法机制，不是氛围。
- 这两个都只在**声音**里给暗示（例如碎玻璃材质的声音更尖更碎），不做数值。

## 2. 第一维：材质（主维度）

| 材质 | 高频 | 尾巴 | 备注 |
|---|---|---|---|
| 木地板 | 中高，有共鸣 | 短回弹 | 老房子基准 |
| 地毯 | 几乎无高频 | 无尾巴，闷响 + 摩擦 | 最容易做出"被吸掉"的对比 |
| 瓷砖/混凝土 | 亮、硬 | 更长，可能有轻微回声 | 冷、空旷 |
| 金属格栅/铁板 | 亮且带金属共振 | 中长，带"嗡" | 恐怖场景常用 |
| 积水/湿石 | 低频糊，带"啪叽" | 短、湿 | 水声要"薄"，别做成泼水 |

**验收判据（这是硬指标）**：蒙住眼睛，只放脚步，人要在**三步之内**说出"木头 / 瓷砖 /
金属 / 有水"。两种材质听混了，就是这一对做得不够，要重做而不是加音量。

## 3. 第二维：脚部（拟人归人形，兽形归兽形）

拟人化的动物角色（灰太狼、红太狼这类）在游戏里就是人形，穿衣、直立、两条腿，
脚**按人形算**——要么穿鞋、要么光脚，没有"爪子"这第三类。爪子是**四足动物**才有的
接触方式，只在真的把猫狗当动物实体表现时才用。

| 脚部 | 接触方式 | 听觉性格 | 适用对象 |
|---|---|---|---|
| 鞋 | 硬底 + 中等面积 + 空腔 | 偏高、带弹、尾音干净 | 穿鞋的人形（含拟人动物穿鞋） |
| 光脚 | 整掌肉垫、面积大、软 | 偏低偏闷的"拍" | 不穿鞋的人形（含懒羊羊这类拟人） |
| 兽足（可选） | 少量硬接触点（爪/趾甲） | 短、脆，木地板带共振 | **仅**四足动物 |

兽足两头极端，别指望一条波形覆盖：犬的趾甲敲木地板会激起局部共振，亮、怪、带金属味；
**猫走木地板几乎一声没有**（肉垫吸收 + 步态轻）。

三条物理变量（不是玄学）：接触面积（大→低频多→闷）、硬度（硬→高频多→脆）、
空气腔（鞋内挤气→短促的"吱/噗"尾）。

## 4. 第三维：速度

真实走路时光脚几乎没声（肉垫吃掉冲击），慢走只剩衣料摩擦；**跑起来才有声，
而且时大时小**（左右脚落点不同、重心起伏、偶尔踩实偶尔擦过）。

"每走一格固定播一次、音量恒定"是错的：

| 状态 | 是否出声 | 音量 |
|---|---|---|
| 常速走（光脚） | 基本不出，或极轻 | −18 dB 级 |
| 常速走（穿鞋） | 轻 | −12 dB 级 |
| 跑 / 疾行 | 明显 | 0 dB 级，**±3 dB 抖动** |
| 停步瞬间 | 偶尔一声轻的"收脚" | 很低 |

**待拍板的取舍**：慢走做到"真实"就等于接近静音，但玩家靠脚步确认"我还在动"。
- **A 真实派**：慢走极轻，跑动才明显。安静得让人不敢跑。
- **B 反馈派**：慢走也留一条很轻的提示声，牺牲真实换可读性。

建议 A，但保留"极轻不等于零"的底线（约 −18 dB）。理由与说框辉光同源：
**玩家需要知道输入被收到了**，否则会怀疑按键失效。

## 5. 房间级的"空间感"（混响是房间的属性，不是脚步的属性）

"水帘洞那种大混响"不是把脚步做响，而是同一个脚步放在**大房间**里：
声音出来带长尾巴、低频更厚。所以混响挂在地图的 `混响` 参数上，与 `地面` 并列：

```json
{ "地面": "湿石", "混响": { "房间大小": 0.8, "湿干比": 0.45 } }
```

渲染库的 `合成器(频率, 毫秒, 选项)` **自带混响**（`混响: {房间大小, 湿干比}`），
另有 EQ、延迟、包络——所以这件事不用等上游，靠合成路径就能做。

注意别过头：混响一重，脚步的"材质辨识度"会被糊掉，与第 2 节的验收判据冲突。
大混响房间建议**降低脚步的干声比例、抬高房间底噪**，让"空间"由环境层表达，
脚步仍保持清楚。

## 6. 数据结构（材质为第一维）

```json
{
  "脚步默认": "木地板/光脚",
  "脚步": {
    "木地板": { "光脚": ["sounds/step/bare_wood_1.wav", "bare_wood_2.wav"],
                "鞋":   ["sounds/step/shoe_wood_1.wav", "shoe_wood_2.wav"] },
    "地毯":   { "光脚": ["sounds/step/bare_rug_1.wav"], "鞋": ["sounds/step/shoe_rug_1.wav"] },
    "金属格栅": { "光脚": ["sounds/step/bare_metal_1.wav"], "鞋": ["sounds/step/shoe_metal_1.wav"] }
  },
  "兽足": { "犬": { "木地板": ["sounds/step/dog_wood_1.wav"] },
            "猫": { "木地板": [] } }
}
```

**查表顺序（三级回退）**：精确命中 `材质/脚部` → 该材质的默认（该材质下第一个可用）
→ 全局 `脚步默认`。只做两三种材质也能跑全套地图，缺的自动退化，不静音、不崩。

触发器是**每走完一格**（逐格移动天然提供节拍点），但**是否播、多响**由第 4 节速度表决定——
"每格触发"不等于"每格都响"。

## 7. 抖动与实现约束（重要，先说清楚）

播放路径分两条，能力**不一样**：

| 路径 | 能否控音量/音调 | 能否混响 | 适用 |
|---|---|---|---|
| `加载音效(wav)` + `播音效(句柄)` | **不能**（无音量、无音调参数） | 不能 | 现成 WAV 直接播 |
| `合成器(频率, 毫秒, 选项)` | 能（音量、包络、EQ、延迟、混响） | 能 | 需要抖动/混响的参数化声音 |

所以在当前 API 下，要做"±3 dB 音量抖动、±3% 音调抖动、房间混响"，必须走**合成器**，
并且**启动时预生成有限变体**（每条脚 × 材质 × 速度档 × 2~3 条抖动 ≈ 十几到几十个句柄），
**不要在走动循环里现合成**——玄铁长循环浮点内存会线性涨（709 字节/轮）。

抖动清单：
1. 每组 2~3 条备选，随机取（不顺序循环）；
2. 音调 ±3%、时长 ±5%；
3. 音量按速度表再叠 ±3 dB；
4. 允许偶尔不播（慢走 30%、跑动 10%）；
5. **EQ（高低频含量）不参与抖动**——它是材质信息位，见 1.1。

不做这几条，前面所有材质区分都会被"发条感"盖掉——这是最容易白干的地方。

## 8. 落地流程：逐条试听，不批量生成

1. 一次只做一个声音；**出声前先报**：播什么、几段、多长
   （例："光脚踩木地板，单步 120ms，三条备选，播四秒"）。
2. 播完由人描述感受（尖 / 闷 / 太干净 / 没有空间 / 像塑料敲铁皮）。
3. 按描述改参数重做，一轮轮收窄，直到人说"就是这个"。
4. 定稿写进音效表 + 资产仓 `sounds/step/`，**参数与听感描述一起记**，能复现。

第一批四件（按优先级）：`木地板/光脚`（基准）→ `瓷砖/鞋`（材质对比）→
`金属格栅/光脚`（金属那一下）→ `木地板/跑动`（速度维度）。
每件都先过"三步盲听能说出材质"这一关，再过"像不像这个人"。
