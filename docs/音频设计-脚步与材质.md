# 音频设计：脚步 = 脚部 × 材质 × 速度

> 状态：**设计定稿，未实现**。一条 WAV 都还没做，这里先把口径钉死，
> 等有闲时按「逐条试听」的方式落地（流程见第 7 节）。

## 0. 为什么单独为脚步写一篇

脚步是玩家听得最多次的声音。一场十分钟的戏，走位可能触发上千次落地——
它的**性格**直接决定这个游戏"像不像"。多数游戏只做一条"穿鞋走硬地"的通铺声，
问题不在省事，而在一条波形反复播放，第一分钟就露出发条感。

## 1. 第一维度：脚部（拟人归拟人，兽形归兽形）

**先分清"角色形体"，再谈脚。** 拟人化的动物角色（灰太狼、红太狼这类）在游戏里
就是人形，穿衣、直立、两条腿，所以他们的脚**按人形算**——要么穿鞋、要么光脚，
不存在"爪子"这个第三类。爪子是**四足动物**才有的接触方式，只在真的把猫狗当
动物实体来表现时才用它。

| 脚部 | 接触方式 | 听觉性格 | 适用对象 |
|---|---|---|---|
| **鞋** | 硬底 + 中等面积 + 空腔 | 偏高、带一点弹、尾音干净 | 穿鞋的人形（含拟人动物穿鞋时） |
| **光脚** | 整掌肉垫、面积大、软 | 偏低偏闷的"拍"，不是"敲" | 不穿鞋的人形（含懒羊羊这类拟人） |
| **兽足**（可选） | 少量硬接触点（爪/趾甲） | 短、脆，木地板会带出共振 | **仅**四足动物实体 |

三条物理变量（第一维度背后的原因，不是玄学）：

- **接触面积**：大 → 低频多、能量摊薄 → 闷、厚、"拍"。
- **接触面硬度**：硬 → 高频多、回弹明显 → 脆、亮、"敲"。
- **空气腔**：鞋内/鞋底纹路挤气 → 短促的"吱/噗"尾。

兽足的真实情况有两头极端，**都别指望一条波形覆盖**：

- 狗的趾甲敲木地板：硬接触点在木板上激起局部共振，声音怪、亮、带"哒"的金属味。
- 猫走木地板：几乎**一声都没有**（肉垫吸收 + 步态轻）。这是真实情况，不是偷懒。

## 2. 第二维度：地面材质

同一只脚踩不同东西，变的是高频含量与尾巴长短：

| 材质 | 高频 | 尾巴 | 备注 |
|---|---|---|---|
| 木地板 | 中高，有共鸣 | 短回弹 | 老房子最常见，做基准 |
| 地毯 | 几乎无高频 | 无尾巴，只有闷响 + 摩擦 | 最容易做出"被吸掉"的对比 |
| 瓷砖/混凝土 | 亮、硬 | 更长，可能有轻微回声 | 冷、空旷 |
| 金属网格/铁板 | 亮且带金属共振 | 中长，带"嗡"的余韵 | 恐怖场景常用 |

## 3. 第三维度：速度（这一维比前两维更影响真实感）

真实走路时**光脚几乎没声**——肉垫把冲击吃掉了，慢走只有衣料摩擦；
**跑起来才有声，而且时大时小**（左右脚落点不同、重心起伏、偶尔踩实偶尔擦过）。

所以"每走一格固定播一次、音量恒定"是错的。正确的关系：

| 状态 | 是否出声 | 音量 | 备注 |
|---|---|---|---|
| 常速走（光脚） | 基本不出，或极轻 | −18 dB 级 | 只留一点布料/肉垫摩擦 |
| 常速走（穿鞋） | 轻 | −12 dB 级 | 鞋底硬，藏不住 |
| 跑/疾行 | 明显出声 | 0 dB 级，**±3 dB 抖动** | 落点差异 + 左右脚交替 |
| 停步瞬间 | 偶尔一声轻的"收脚" | 很低 | 有则更像人，没有也不突兀 |

**这里有一个必须由人来拍的设计取舍**：光脚慢走做到"真实"就等于**接近静音**，
而玩家在恐怖游戏里恰恰靠脚步声确认"我还在动"。两种解法：

- **A 真实派**：慢走极轻（不是零），跑动才明显。安静得让人不敢跑。
- **B 反馈派**：慢走也保留一条很轻的提示声，牺牲真实换可读性。

我的建议是 A，但要保留一个"极轻不等于零"的底线（约 −18 dB），否则玩家会怀疑
按键没生效——这和说框辉光是同一个问题：**玩家需要知道"输入被收到了"**。

## 4. 数据结构（落地时照这个写）

```json
{
  "脚步默认": "光脚/木地板",
  "脚步": {
    "鞋":   { "木地板": ["sounds/step/shoe_wood_1.wav", "shoe_wood_2.wav"],
              "地毯":   ["sounds/step/shoe_rug_1.wav", "shoe_rug_2.wav"] },
    "光脚": { "木地板": ["sounds/step/bare_wood_1.wav", "bare_wood_2.wav"],
              "地毯":   ["sounds/step/bare_rug_1.wav", "bare_rug_2.wav"] }
  },
  "兽足": {
    "犬": { "木地板": ["sounds/step/dog_wood_1.wav"] },
    "猫": { "木地板": [] }
  }
}
```

**查表顺序（三级回退）**：精确命中 `脚部/材质` → 该脚部的默认 → 全局 `脚步默认`。
只做四种声音（鞋、光脚 × 木地板、地毯）也能跑全套地图，缺的自动退化，不静音、不崩。

- 角色属性给一个 `脚部`（鞋 / 光脚 / 兽足·犬 / 兽足·猫）；
- 每张地图给一个 `地面`（材质名）；
- 触发器是**每走完一格**（逐格移动天然提供节拍点），但**是否播、音量多大**由第 3 节
  的速度表决定——所以"每格触发"不等于"每格都响"。

## 5. 抖动：让重复不变成发条（硬要求）

1. 每组准备 **2~3 条**备选，随机取（不按顺序循环）；
2. 叠加**音调 ±3%、时长 ±5%** 的随机微扰；
3. 音量按速度表再叠加 **±3 dB**；
4. 允许**偶尔不播**（慢走时跳过的比例更高，约 30%；跑动约 10%）。

不做这几条，前面所有区分都会被"发条感"盖掉。

## 6. 合成还是实录

结论：**这一层用合成，接口留成可替换**。

- 脚步短（80–150 ms）、无音高、纯冲击 + 摩擦噪声，人耳判节奏与频谱包络 → 合成够用。
- 合成可**参数化调参**：听感不对时说"高频太重"能直接调；实录只能整体重录。
- 实录无可替代的是**环境**（房间混响、地板不平、每步差异）。这些放引擎侧：
  混响按房间走 + 第 5 节的抖动。

例外：门轴吱呀、木头受力的呻吟这类**非冲击、带摩擦演化**的声音，合成难做出"偶发"感，
实录更值。

## 7. 落地流程：逐条试听，不批量生成

1. 一次只做一个声音；**出声前先报**：播什么、几段、多长
   （例："光脚踩木地板，单步 120ms，三条备选，播四秒"）。
2. 播完由人描述感受（尖 / 闷 / 太干净 / 没有空间 / 像塑料敲铁皮）。
3. 按描述改参数重做，一轮轮收窄，直到人说"就是这个"。
4. 定稿写进音效表 + 资产仓 `sounds/step/`，**参数与听感描述一起记**，能复现。

第一批只要四个：`光脚/木地板`（基准）、`鞋/木地板`、`光脚/地毯`、`跑动/木地板`
（第四条是速度维度，值得早做，不然慢走静音跑动有声的对比做不出来）。

## 8. 与玄铁侧的限制

- 短音安全：90 ms / 1984 样本实测 1~2 ms、内存增量可忽略（见 AGENTS「已知坑」7）。
- **长音频与逐样本合成不要在玄铁里做**：浮点长循环约 709 字节/轮线性上涨。
- 所以 WAV 由外部程序生成（`文字剧情/生成音效.py` 的 FM 路径或独立脚本），
  玄铁侧只 `加载音效` / `播放音效`。
- 目前渲染库没有流式回调，采样循环在 C 层——短音够用，别指望做连续音景。
